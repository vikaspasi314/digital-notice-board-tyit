# Digital Notice Board Management System

TYIT subject project built with PHP, MySQL, HTML and CSS.

## Features
- Public homepage showing all notices (newest first)
- Admin login with session protection
- Admin dashboard to add new notices
- Logout

## Technologies
HTML5, CSS3, PHP, MySQL, XAMPP (Apache), Git/GitHub

## How to run
1. Install XAMPP and start Apache and MySQL
2. Copy this folder into `htdocs`
3. Open phpMyAdmin and import `database.sql`
4. Visit `http://localhost/notice-board/`
